# CampusFound

CampusFound is a Flutter lost-and-found app for university communities. Students can report lost or found items, search and filter unresolved reports, contact other students through item-linked chat, and manage their own reports from a dashboard.

## Run the app

```text
flutter pub get
flutter run
```

Firebase configuration is required for the full authentication, Firestore, and real-time chat workflow. The login screen also includes Demo Mode for local feature exploration.

## Test

```text
flutter test
```

The current repository test suite passes 12 tests covering models, campus geolocation utilities, date helpers, chat behavior, and a basic widget rendering path.
