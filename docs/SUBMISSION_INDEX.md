# CampusFound Submission Index

This folder organizes the required submission materials.

| Requirement | Location/status |
|---|---|
| Final project ZIP | Create from the repository root after adding final screenshots and report assets. |
| Project report PDF | Export `PROJECT_REPORT.md` to PDF after replacing contribution placeholders and recording test results. |
| Important-feature screenshots | Capture using `SCREENSHOT_CHECKLIST.md`; store under `docs/screenshots/`. |
| Screen-flow diagram | Section 3 of `PROJECT_REPORT.md` (Mermaid). Export as an image if the course requires static diagrams. |
| Data-flow diagram | Section 4 of `PROJECT_REPORT.md` (Mermaid). Export as an image if the course requires static diagrams. |
| State, CRUD, search/filter, folder explanations | Sections 5, 6, and 13 of `PROJECT_REPORT.md`. |
| Testing evidence | Section 8 plus `10-test-results.png`. |
| Observation, limitations, conclusion | Section 10 and Section 11. |
| Contribution summary | Section 12; replace all placeholders with actual names and work. |

## Final packaging checklist

- [ ] Run `flutter test` and paste the real result into the report.
- [ ] Complete the screenshot checklist.
- [ ] Replace team-member placeholders.
- [ ] Export the report to PDF.
- [ ] Confirm the ZIP does not contain secrets or unnecessary build artifacts.
- [ ] Open the PDF and screenshots once before submission.
